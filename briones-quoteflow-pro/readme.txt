Briones QuoteFlow Pro acts as a scalable premium extension to the core Briones QuoteFlow Free plugin, unlocking enterprise B2B features like Webhooks, CRM integrations, and advanced analytics.

== Description ==

This plugin is strictly an add-on. It relies completely on the database architecture, CRM interfaces, and APIs provided by the Briones QuoteFlow Free core plugin.

Do not install this plugin if you have not installed and activated the free version first.

=== Roadmap ===
* Webhooks
* HubSpot & Zoho Integrations
* n8n & Automations
* Advanced Analytics

== Installation ==

1. Install and activate `Briones QuoteFlow Free`.
2. Upload the `briones-quoteflow-pro` directory to your `/wp-content/plugins/` directory.
3. Activate the plugin through the 'Plugins' menu in WordPress.
4. Navigate to the new 'QuoteFlow Pro' menu.
